# 🕯️ Light of Seneca

Стоический планировщик на основе мудрости Сенеки. Темная тема, минимализм, фокус на продуктивности.

## 🚀 Быстрый старт
```bash
git clone [repo]
npm install
npm run dev
```

## 📦 Основные модули
- Задачи с приоритетами
- Трекер привычек  
- Pomodoro таймер
- Стоический дневник
- Система уровней (XP)

## 🏛 Философия
Приложение построено на принципах Сенеки:
- Управление временем
- Развитие добродетелей
- Ежедневная рефлексия
